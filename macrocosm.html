How far away is that galaxy?

Distance is the hardest thing to measure in astronomy — and the key to almost everything else.

The exact way — spectroscopy

Split a galaxy's light into a spectrum and read its redshift. Accurate to 0.0001 — but slow & expensive: a few targets at a time, hours of telescope time each.

The cheap way — a picture

Surveys already photograph billions of galaxies in 5 color filters. The distance is hidden in the pixels — we just can't read it by eye.

The idea

Teach a model to predict the expensive spectroscopic redshift straight from the cheap image — turning an hours-long measurement into milliseconds.

The signal, by eye

You can almost see the distance

8 real SDSS galaxies, ordered by their true redshift — watch them shrink and redden as they get farther away

That visible trend — fainter, smaller, redder with distance — is what the model learns to read. No spectrum needed.

Primary Goal · The Input

One galaxy, five filters

What we actually feed the model — pulled live from SDSS DR17 via astroquery

ugriz cutouts → the model input pulled via astroquery

Every object is imaged in 5 bands (u g r i z). Stack them → X_img = (64, 64, 5). The brightness & shape shifts across bands are what encode redshift — invisible to the eye, learnable by a CNN.

Primary Goal · Data Access

Pulling the data with astroquery

Two calls build the whole dataset: one SQL join for labels + features, one image fetch per object

1 · Tabular — SQL join PhotoObj × SpecObj

# spectroscopic z (label) + photometry (features)
SELECT TOP 100000
  p.objid, p.ra, p.dec,
  p.modelMag_u, p.modelMag_g, p.modelMag_r,
  p.modelMag_i, p.modelMag_z, p.petroR50_r,
  p.run, p.camcol, p.field,      # locate frames
  s.z AS redshift
FROM PhotoObj p
JOIN SpecObj s ON s.bestObjID = p.objID
WHERE s.class='GALAXY' AND s.zWarning=0
  AND p.clean=1
  AND s.z BETWEEN 0.02 AND 0.35

Primary Goal · Model

Initial model design

Tabular baseline first for a fast benchmark → CNN on images → fuse both into one regressor

Architecture — two branches, one redshift head

X_img (64,64,5) ──► [ Conv×4 → BN → GlobalAvgPool ] ──► img_feat (128) │ ▼ concat X_tab (n) ──────────► [ StandardScaler / BN ] ──────► [ Dense 64 → Dense 32 ] ──► ẑ (redshift)

Baseline → Main

Baseline: XGBoost on the tabular features → z. Trains in seconds, sets the bar & wires the webapp early.

Main: small CNN on (64,64,5) arcsinh-stretched cutouts, then fuse image features + tabular into a dense head.

Training & metrics

Loss: Huber/MSE on z · Adam + early stopping · split 70/15/15.

Report σ_MAD, bias ⟨Δz⟩, outlier rate (|Δz|/(1+z)>0.05), and a z_pred vs z_spec scatter. Target σ_MAD < 0.01.

Guardrail: observed-frame inputs only — never feed absMag/kcorr (derived from z → leakage). Stretch images, augment with flips/rotations.
