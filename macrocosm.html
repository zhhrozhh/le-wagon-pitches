Primary Goal

Predicting Galaxy Redshift from Astronomical Images

Estimate redshift (distance) directly from cheap imaging with machine learning

Background

Redshift z tells a galaxy's distance & recession velocity — the backbone of cosmology. The exact way to get it is spectroscopy: accurate but slow & expensive, only a few targets at a time.

Model Value

Imaging is cheap & everywhere — every object already has it. We learn to predict the expensive spectroscopic z from cheap photometry/images. Benchmark: σ_MAD < 0.01 (Pasquet 2019).

Vetting False Positives in Transit Light Curves

Classical BLS/TLS finds the dip — ML decides: real planet or false positive?

Background

A planet crossing its star dims it periodically. Finding the dip is solved by BLS/TLS. The hard part is the false positives — mostly eclipsing binaries that mimic the same dip.

Model Value

Vetting was done by humans / decision trees — doesn't scale to millions of TESS candidates. ML learns the subtle tells (V-vs-U shape, secondary eclipse, odd-even depth) to auto-triage at scale.

Backup Goal

Unsupervised Detection of Anomalous Objects

Let the model rank the universe by "weirdness" and surface candidates for follow-up

Background

Surveys catalog billions of objects — almost all ordinary. The discoveries (rare quasars, odd galaxies, new classes) hide in the outliers. No labels exist for "interesting".

Model Value

An autoencoder learns to reconstruct normal objects; high reconstruction error = anomaly. Surfaces the rare few from millions without any labels, for humans to inspect.
